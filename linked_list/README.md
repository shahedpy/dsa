# Linked List
## What is a Linked List?
A linked list is a linear data structure where each element (node) contains:
- Data (the value)
- A reference (pointer)
## Types of Linked Lists
- **Singly Linked List:** Each node points to the next node
- **Doubly Linked List:** Each node points to both the previous and the next node.
- Circular Linked List: The last node points back to the first node.
## Key Operations
- **Insertions:** Add a node at the beginning, end, or middle.
- **Deletion:** Remove a node by value or position.
- **Traversal:** Visit all nodes in order.
## Advantages Vs Disadvantages
### Advantages
- Dynamic size
- Efficient insertions and eletions
### Disadvantages
- Sequential access only (no random access)
- More memory usage due to pointers.
